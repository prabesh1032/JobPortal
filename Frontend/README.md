# 🐦 HireNest — Job Portal

A full-stack **Job Portal** web application built with **React.js + Laravel** (REST API), later migrating to the full **MERN Stack** (MongoDB, Express.js, React.js, Node.js). Designed for both job seekers and recruiters to connect seamlessly.

## 🔗 Live Demo
> Coming soon — deploying on Vercel + Render

## 🛠️ Tech Stack

### Current Stack
- **Frontend** — React.js, Tailwind CSS, React Router, Lucide Icons
- **Backend** — Laravel (PHP) *(in progress)*
- **Database** — Postgrasql
- **Auth** — Laravel Sanctum / JWT *(in progress)*

### Future Migration
- **Backend** — Node.js + Express.js
- **Database** — MongoDB + Mongoose
- **Auth** — JWT Authentication

## ✨ Features
- 🔍 Search & filter jobs by title, location, and category
- 💼 Job listings with company info, salary, and skills
- 👤 Separate dashboards for Job Seekers & Recruiters
- 📝 Recruiter can post, edit & delete jobs
- 📄 Job Seeker can apply and track applications
- 🔐 JWT-based login & role-based access control
- 📱 Fully responsive — mobile friendly
